# Exercices PHP

Exercices du cours Bases de données et développement back-end, accompagnés de leurs ressources et notes.

Les dossiers `exercice_*` contiennent les exercices du syllabus ; `exo` contient les exercices complémentaires.

## Utilisation

Démarrer Apache dans XAMPP, puis ouvrir http://localhost/ pour accéder à la liste des exercices lorsque le dépôt se trouve dans `C:\xampp\htdocs`.

Les exercices utilisant une base de données nécessitent également MySQL et la configuration de la base correspondante.
